# ربات فروش VPN (aiogram 3 + 3x-ui)

ربات تلگرام فروش اشتراک VPN با پنل مدیریت درون‌ربات و اتصال به پنل **3x-ui**.
تمام رابط کاربری فارسی است.

## امکانات

**کاربر (کیبورد پایین):**
- 🎁 **تست رایگان** — یک‌بار برای هر کاربر، ساخت آنی کانفیگ
- 🛒 **خرید اشتراک** — انتخاب مدت ← پکیج ← صفحه تأیید (خلاصه) ← پرداخت کارت‌به‌کارت ← ارسال رسید
- ♻️ **تمدید سرویس** — تمدید همان کلاینت روی پنل
- 📋 **سرویس‌های من** — مشاهده حجم و روزهای باقی‌مانده، کپی کانفیگ
- 🏅 **امتیاز من** — تبدیل امتیاز به روز اشتراک هدیه
- 👥 **دعوت از دوستان** — لینک اختصاصی؛ امتیاز در اولین خرید دعوت‌شده
- 📚 **آموزش استفاده** و ☎️ **پشتیبانی**

**ادمین (دکمه «🛠 پنل مدیریت» فقط برای ADMIN_IDS):**
- تأیید/رد رسید به‌صورت اینلاین؛ با تأیید، کانفیگ **خودکار** برای کاربر ارسال می‌شود
- ویرایش همه متن‌ها و تصویر خوش‌آمد، شماره کارت و راهنمای پرداخت
- مدیریت مدت‌ها و پکیج‌ها (افزودن/ویرایش/فعال‌سازی/حذف)
- تنظیمات تست رایگان و امتیاز/رفرال
- مدیریت کاربران (مسدودسازی، هدیه امتیاز)، آمار، پیام همگانی، تست اتصال پنل

## راه‌اندازی با Docker (پیشنهادی)

```bash
cp .env.example .env          # مقادیر را پر کنید (توکن، ادمین‌ها، پنل)
docker compose up -d --build  # ساخت و اجرا در پس‌زمینه
docker compose logs -f        # مشاهده لاگ‌ها
docker compose down           # توقف
```

دیتابیس در پوشه `./data` روی هاست ذخیره می‌شود و بین اجراها/به‌روزرسانی‌ها
حفظ می‌ماند. پس از تغییر کد: `docker compose up -d --build`.

## راه‌اندازی بدون Docker

```bash
python -m venv .venv
.venv/Scripts/activate        # ویندوز:  .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env          # مقادیر را پر کنید (توکن، ادمین‌ها، پنل)
python bot.py
```

دیتابیس SQLite در اولین اجرا در `data/bot.db` ساخته می‌شود و مقادیر پیش‌فرض
تنظیمات درج می‌شوند. سپس از داخل تلگرام با «🛠 پنل مدیریت» متن‌ها، تصویر،
مدت‌ها و پکیج‌ها را تعریف کنید.

## متغیرهای محیطی مهم (`.env`)

| کلید | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | شناسه عددی ادمین‌ها با کاما، مثال `111,222` |
| `RECEIPTS_CHAT_ID` | چت دریافت رسیدها؛ خالی = ادمین اول |
| `XUI_BASE_URL` | آدرس پنل، مثال `https://host:2053` |
| `XUI_WEB_BASE_PATH` | مسیر پایه پنل در صورت وجود |
| `XUI_USERNAME` / `XUI_PASSWORD` | ورود پنل |
| `XUI_NODE_HOST` | دامنه/آی‌پی داخل لینک کانفیگ کاربر |
| `XUI_SUB_BASE_URL` | آدرس پابلیک subscription (اختیاری) |
| `XUI_VERIFY_SSL` | برای گواهی self-signed مقدار `false` |

## نکات پنل 3x-ui
- شماره **inbound** هر پکیج در پنل مدیریت قابل تنظیم است (پیش‌فرض `1`).
- لینک اتصال از روی `streamSettings` همان inbound ساخته می‌شود
  (reality/tls/ws/grpc/tcp پشتیبانی می‌شود).
- `totalGB` در پنل بایت است و `expiryTime` میلی‌ثانیه؛ این تبدیل‌ها داخلی انجام می‌شود.

## ساختار

```
bot.py                      نقطه ورود، wiring دیسپچر و زمان‌بند
app/config.py               تنظیمات از .env
app/db/                     مدل‌ها (SQLAlchemy 2 async) و نشست
app/services/
  vpn/                      کلاینت 3x-ui + سازنده لینک (قابل تعویض پنل)
  provisioning.py           ساخت/تمدید سرویس
  points_service.py         امتیاز و رفرال
  settings_service.py       تنظیمات قابل ویرایش ادمین
app/keyboards/              کیبورد پایین و اینلاین‌ها
app/handlers/               common/trial/buy/services/points/misc + admin/
app/scheduler.py            همگام‌سازی مصرف و یادآوری انقضا
app/texts.py                متن‌ها و مقادیر پیش‌فرض فارسی
```

معماری پنل پشت `VpnProvider` (در `app/services/vpn/base.py`) انتزاع شده تا
در آینده افزودن Marzban/Hiddify ساده باشد.
